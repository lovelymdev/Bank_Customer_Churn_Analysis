# Bank Customer Churn Analysis

## Project Overview

This project analyzes customer churn behavior in a banking dataset using Excel, SQL, and Power BI.

The objective is to identify customer segments with higher churn risk and present business insights through an interactive Power BI dashboard.

---

## Tools Used

- Excel
- SQL
- Power BI
- DAX
- GitHub

---

## Dataset

- 10,000 Customers
- 15 Features
- Banking Customer Records
- Customer Exit Status

---

## Project Workflow

1. Data Cleaning in Excel
2. Feature Engineering
3. SQL Data Analysis
4. KPI Calculation
5. Power BI Dashboard Development
6. Business Insight Generation

---

## Dashboard KPIs

- Total Customers: 10,000
- Churned Customers: ~2,037
- Churn Rate: 20.37%
- Active Members: ~5,000
- Average Balance: ~76K
- Average Credit Score: 651

---

## Dashboard Features

- Customer Distribution by Country
- Churn Analysis by Credit Score
- Churn by Age Group
- Gender-wise Exit Analysis
- Customer Type Segmentation
- Interactive Filters

---

## Key Insights

- Overall churn rate is 20.37%.
- France has the highest customer base.
- Customers aged 51–60 contribute the largest share of churn.
- Customers with Fair credit ratings show the highest exits.
- Active membership is associated with lower churn.
